# cinnamon

A clean GitHub Profile Achievements tracker, CLI cheatsheet, and open collaboration hub.

## Earnable GitHub Achievements

| Achievement | Criteria | Tiers | Status |
| :--- | :--- | :--- | :--- |
| **YOLO** | Merge a PR without code review | Single | Earned |
| **Quickdraw** | Close an issue or PR within 5 minutes of opening | Single | Earned |
| **Pull Shark** | Merge pull requests | `2` / `16` / `128` / `1024` | Earned (Base — 3+ merged PRs) |
| **Pair Extraordinaire** | Co-author a commit in a merged PR | `1` / `10` / `24` / `48` | Needs collaborator |
| **Galaxy Brain** | Have answers marked as accepted in Q&A Discussions | `2` / `8` / `16` / `32` | Needs collaborator |
| **Starstruck** | Own a public repository with stars | `16` / `128` / `512` / `4096` | Needs stars |
| **Public Sponsor** | Sponsor an open-source developer via GitHub Sponsors | Single | External |

> Retired / internal badges (*Arctic Code Vault*, *Mars 2020*, *Finishing Touch*, *Proxima*, *Heart On Your Sleeve*, *Open Sourcerer*) are excluded because they are no longer publicly earnable.

## Quick Badge Checker

Check which achievement slugs are currently visible on any public GitHub profile:

```bash
./check-badges.sh VhalennnG
```

## Collaborating for Badges

- **Galaxy Brain:** Open a question in the **Discussions** tab (`Q&A` category) or answer open questions so the author can mark the accepted answer.
- **Pair Extraordinaire:** See [CONTRIBUTING.md](./CONTRIBUTING.md) for how to submit a co-authored commit using the `Co-authored-by:` trailer.
- **Starstruck:** If this tracker or script helped you, feel free to star the repository.
