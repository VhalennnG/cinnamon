# Contributing

Contributions, Q&A discussions, and collaborative pull requests are welcome.

## Pair Extraordinaire (Co-authored PRs)

To co-author a commit with another GitHub contributor, add a blank line followed by one or more `Co-authored-by:` trailers at the end of your commit message:

```bash
git commit -m "docs: update achievement notes

Co-authored-by: CollaboratorName <123456+username@users.noreply.github.com>"
```

Make sure:
1. The email matches a verified email (or GitHub noreply email) of a real collaborator's GitHub account.
2. The commit is part of a Pull Request merged into `main`.

## Galaxy Brain (Q&A Discussions)

1. Open a question under **Discussions -> Q&A**.
2. Wait for another contributor to answer.
3. Mark the helpful reply as the **Accepted Answer**.
